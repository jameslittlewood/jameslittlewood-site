# Mythic+ dashboard artwork

The nine SVG files in this directory (the hero and eight dungeon illustrations)
were created for this project as original abstract vector artwork. They use only
gradients, geometry and silhouettes. No Raider.IO, Blizzard Entertainment or
third-party artwork is copied, scraped or redistributed.

These assets are part of the local site working copy and are intended to ship
with the dashboard under the project's existing website licence.
